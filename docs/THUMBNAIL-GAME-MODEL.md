# Model Thumbnail GAME (hasil belajar 2026-11-10)

Beda fundamental dari model podcast: di podcast "wajah" = pembicara;
di game "wajah" = KARAKTER game atau wajah facecam kreator. Tanpa
facecam (kasus dunkey), karakter mengambil peran wajah.

## Aturan model game
1. Teks PALING sedikit dari semua model: 0-2 kata ideal, maks 3.
   (Data industri: thumbnail 0-2 kata ~6,8% CTR vs 4,3% untuk 6+ kata.)
   Podcast memakai 3-5 kata pertanyaan; game memakai 1-3 kata ledakan.
2. Karakter/render game close-up sebagai fokus tunggal >=40% frame;
   screenshot mentah kalah dari momen beku dramatis / render bergaya.
3. Saturasi DITINGGIKAN (+20-35%): palet neon (biru elektrik, hijau,
   merah, kuning). Merah dilaporkan ~23% lebih banyak diklik dari biru.
4. Teks kuning/putih + stroke hitam tebal = keterbacaan maksimum.
5. Rim light / outline menyala di sekitar karakter agar lepas dari
   latar gameplay yang ramai.
6. Isyarat visual klasik: lingkaran/panah merah pada objek penasaran
   (dipakai hemat, maks 1), komposisi versus / before-after.
7. Benchmark niche: CTR game tertinggi di YouTube (~8,5% rata-rata).
8. Wajah manusia (bila facecam ada): reaksi berlebihan >=35% frame,
   mata menatap kamera; thumbnail berwajah +15-30% CTR vs tanpa wajah.

## Adaptasi Shorts (9:16)
- Karakter memenuhi bingkai vertikal; teks di pita aman tengah-atas,
  tidak tertutup UI kanan/bawah.
- Uji keterbacaan di lebar rak Shorts (~135px), bukan cuma 168px.

## Sumber bahan (ditambahkan 2026-11-10)
Tiga jalur, urutan prioritas gabungan:
1. Render/key art resmi game (pencarian gambar; wiki game menyediakan
   PNG transparan siap cut-out) - memecahkan masalah karakter kecil/
   dari belakang pada frame gameplay. Bukti: thumbnail asli dunkey
   untuk video sumber klip #1 adalah key art resmi Ocarina of Time 3D
   apa adanya (1280x720, tanpa teks tambahan).
2. Thumbnail YouTube video sumber (yt-dlp/i.ytimg.com maxresdefault) -
   sebagai REFERENSI komposisi & tolok ukur, bukan ditempel mentah
   (identitas channel + risiko duplikasi).
3. Frame gameplay sendiri - latar/konteks otentik di belakang render.
Catatan hak: key art/render adalah karya promosi pemegang hak cipta;
pemakaian sebagai thumbnail klip/komentar adalah praktik standar
ekosistem kreator, bukan lisensi umum.
